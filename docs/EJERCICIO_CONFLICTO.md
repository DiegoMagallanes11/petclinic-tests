# Ejercicio controlado de conflicto Git

Validacion: pruebas de persistencia con H2 y pruebas unitarias aisladas con Mockito.

Se resolvio un conflicto real de contenido entre feature/cierre-laboratorio y practica/validacion-mockito al modificar la misma linea. Se conservaron ambas descripciones porque las pruebas H2 y Mockito cumplen funciones complementarias.

Esta fue una practica deliberada realizada bajo la identidad de Diego. No fue un conflicto ocurrido durante los PR de implementacion ni representa cambios hechos por Angel. El docente debe valorar si esta practica satisface su requisito de conflicto en equipo.

Las salidas originales de Git y los marcadores estan en docs/evidencias. El merge de resolucion conserva los dos commits divergentes.
